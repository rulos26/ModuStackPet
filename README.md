# ModuStackPet

ModuStack — SaaS veterinario: administración de guarderías y clínicas caninas

**Repositorio:** https://github.com/rulos26/ModuStackPet


## Docker

```bash
docker compose up --build
```

App: http://localhost:8081

En Laravel, el .env debe usar `DB_HOST=mysql` y `DB_PORT=3306` cuando corre en Docker.
